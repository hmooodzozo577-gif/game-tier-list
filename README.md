# ميزان الألعاب

قائمة ترتيب (Tier List) فيها ٢٨٧ لعبة من أشهر ألعاب كل الأجيال و١٣ فئة تقدر تعدّلها وتزيد عليها.
رتّب الألعاب بالسحب أو بالضغط، وشارك صورة ترتيبك مع الشباب. ترتيب كل شخص ينحفظ في جهازه.

الموقع: https://hmooodzozo577-gif.github.io/game-tier-list/

صور الأغلفة مأخوذة من ويكيبيديا، وحقوقها لأصحابها من الناشرين والمطورين.
